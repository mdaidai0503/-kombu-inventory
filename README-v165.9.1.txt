昆布在庫管理 v165.9.1 安定版

【重要】
v165.9で発生した「ページが応答しません」を修正しました。
原因は画面監視中に同じDOMを書き換え続けるループです。

【今回の修正】
1. ④出荷明細
   上段: 昆布の種類 / 生産年度
   下段: 漁協 / 区分 / 等級
   左寄せで配置

2. 出荷可能在庫
   v165.9.1では独自再計算を行いません。
   本体 + v165.7 の既存の正しい計算をそのまま利用します。
   これにより釧路などで436のような誤表示を起こさないようにしました。

3. 年度表示
   R7 → R7年産
   R7年 → R7年産
   新規出荷依頼・在庫管理画面で統一。

4. 送り状確認
   - FAX受信月ごとに折りたたみ
   - 最新月のみ初期展開
   - 要確認/不一致/未判定の操作欄右端に削除
   - 削除前にPDFプレビュー
   - 「本当に削除しますか？」確認
   - 自動添付済み表示の下に削除済PDF
   - 削除済PDFは閲覧可能
