昆布在庫管理 v165.8 修正パッチ

変更内容
1. 新規出荷依頼「④出荷明細」
   昆布の種類 → 生産年度 → 漁協 → 区分 → 等級
   の順に変更し、全体を左寄せでバランスよく配置。

2. 送り状確認
   - 要確認・不一致・未判定の操作欄右端に「削除」ボタン追加。
   - 削除ボタン → PDF確認画面 → 「本当に削除しますか？」→ 削除。
   - 実ファイルは即時物理削除せず、Supabase上で「削除済」として保管する安全方式。
   - 「自動添付済みを表示」の下に「削除済のPDF」閲覧欄を追加。
   - 削除済PDFはPDFボタンから閲覧可能。

3. 送り状確認をFAX受信月ごとに折りたたみ。
   - 最新月だけ初期表示で開く。
   - 過去月は閉じた状態。
   - 各月に件数表示。
