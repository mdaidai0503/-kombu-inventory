# 昆布在庫管理（業務用設定版）

実際の「R6年度 釧路産昆布 在庫証明書」に合わせた初期マスターを設定しています。

## 漁協
- 東部漁協
- 昆布森漁協
- 厚岸漁協
- 散布漁協
- 浜中漁協

## 等級・区分
- 花
- 特長
- 厚頭
- 長頭
- 加工用
- 2段目10kg

在庫表は「漁協名」を行、「等級・区分」を列として集計します。

## GitHub Pages
1. リポジトリを開く
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: main / Folder: /(root)
5. Save

## iPhone
公開URLをSafariで開き、「共有」→「ホーム画面に追加」でアプリのように利用できます。

## データ
入出庫データはiPhoneのブラウザ内（localStorage）に保存し、GitHub Pagesへ送信しません。
機種変更・Safariのデータ削除に備えて、定期的に「バックアップ保存」を行ってください。


修正版 v2: ホーム画面の「📦 出荷指示」表示不具合を修正。Service Workerキャッシュをv5へ更新。


修正版 v3: 「コケ」「特長・特特」をアプリ内の全分類から削除。


## PDFから入庫（v8）
- 入庫登録画面の「PDFから入庫」から在庫証明書PDFを選択できます。
- 東部→昆布森→厚岸→散布→浜中、夏・秋・拾、細分類、数量を自動解析します。
- 登録前に件数・合計数量・明細を確認できます。
- PDF本体のSHA-256ハッシュを保存し、同じPDFの二重入庫を防止します。
- PDF解析はブラウザ内で行い、選択したPDFそのものをサーバーへ送信しません。


修正版 v10: 生産年度（R3〜R10）を追加。入庫・出庫・PDF取込・在庫表・履歴・出荷指示・Excel/CSVを年度別管理に対応。既存の年度未設定データはR7年産として移行。


修正版 v11: 50〜60ページ程度のPDF全体を走査し、「釧路産昆布」（棹前昆布を除く）だけを抽出。R3〜R10の生産年度を自動判定し、取引先をまたいで年度・漁協・夏秋拾・細分類ごとに合算して一括入庫する機能を追加。


## 出荷指示・生産年度・在庫反映（v12）
- 出荷指示に「基本生産年度」を追加し、各明細にも R3〜R10 の生産年度を保持します。
- 出荷指示を「確定」すると、該当する年度・漁協・区分・細分類の在庫表から数量を即時差し引きます。
- 下書き保存では在庫を変更しません。
- 確定済み指示を取消した場合は、引当数量が自動的に在庫表へ戻ります。
- 「出荷済み」にすると正式な出庫履歴を作成します。確定時の引当から二重に減算されません。
- 在庫表・ホーム総在庫・Excel/CSVは確定済み出荷指示を差し引いた利用可能在庫を表示します。
