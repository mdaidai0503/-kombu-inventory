昆布帳 v0.1.45

見積 → 出荷依頼の流れ
1. 見積を選択すると、商品名から昆布の種類・漁協や区分・等級と本数を自動入力します。
2. 下の年産欄で年産を選択します。商品名にある西暦やR表記は年産として確定しません。
3. 「一括転記」を押すと、選択した年産の帳票セルへ本数をまとめて転記します。
4. 判別が曖昧な明細だけ、分類を修正または今回は取り込まない設定にしてください。

対応
・釧路、根室、日高、釧路棹前、羅臼（通常）、羅臼（長切）。
・羅臼の黒走、黒走白、黒走傷、黒羅、黒羅傷、天然／養殖加工、赤葉、頭等の分類。
・本数の自動入力、既存の出荷先読込み、在庫不足・重複取込みの確認。
・分類候補では年産を表示せず、後で指定した年産と数量単位で在庫を確定します。
・見積選択後は、初期表示の空の釧路帳票を残しません。
・在庫確定・FAX連携・本数からkgへの換算は従来どおりです。

検証：node shipment-cells.test.cjs
商品名の西暦を無視し、後から選択したR年産へ一括転記できること、
6種類の分類、在庫単位の確認、PDF数量セル、在庫残高の検証が通過しています。
