昆布在庫管理 v165.9.2

【今回の仕様変更】

1. 新規出荷依頼 ④出荷明細
   上段：昆布の種類 / 生産年度 / 漁協
   下段：区分 / 等級 / 数量
   左寄せで配置します。

2. 数量
   プルダウンにはせず「直接入力」を維持します。
   入力できるのは正の整数だけです。
   小数点、マイナス、e 等は入力できません。

3. 出荷可能在庫
   計算処理は変更しません。
   本体 + v165.7 の正しい在庫計算をそのまま使います。

4. 出荷依頼履歴
   現在の出荷依頼履歴（v136HistBody）を対象に月ごとの折りたたみを実装。
   最新月は初期表示で開き、それ以前は折りたたみます。
   取消済は従来仕様どおり最下部に独立してまとめます。
   フィルタ・並び替え後も月別に再整理します。

5. 送り状確認
   v165.9.1 の修正内容を維持します。
